# 简历筛选 Agent 使用说明

适用版本：Windows 桌面版 0.1.3

## 安装与首次启动

1. 双击 `Resume-Screening-Agent-Setup-0.1.3.exe`，按提示完成安装。
2. 从桌面快捷方式或开始菜单启动“简历筛选 Agent”。首次启动可能需要几秒钟。
3. 打开“设置”，配置模型服务商、模型名称、接口地址和 API Key，然后保存设置。可使用“拉取模型”获取服务商提供的模型名称；若拉取失败，也可按服务商文档手动填写。
4. 如需邮件收件或发送面试邀请，在“设置”中配置 QQ 邮箱预设，或填写其他邮箱的 IMAP/SMTP 地址及客户端授权码，点击“测试并保存”。邮箱登录密码不能代替服务商要求的客户端授权码或应用专用密码；仅支持可使用 IMAP/SMTP 凭据登录的邮箱，OAuth-only 账户暂不支持。
5. 如需把简历文件另存到指定文件夹，在“设置”中启用“简历本地归档”，选择文件夹和保存时间，再保存归档设置。

模型 API 会处理完成解析和评分所需的岗位描述及简历内容。请先确认公司允许使用所配置的模型服务，并符合公司的个人信息处理要求。

## 创建岗位与评分

1. 在“岗位池”选择“新增岗位”，填写岗位名称和完整 JD。
2. 点击“生成评分标准”。系统生成草稿后，HR 可在“审核评分标准”中调整评分维度、分值、必备条件、优先项、风险提示及分数封顶规则。修改评分标准时，请检查权重总和是否为 100 分。
3. 在“确认创建”查看岗位摘要和“评分标准完整性检查”。“需核对”是提醒，不会自动修改规则；请结合岗位要求逐项判断，再确认创建。
4. 当前系统只展示评分结果，不根据分数自动淘汰、推荐面试或设置复核阈值。招聘决定由 HR 结合简历证据和公司流程作出。
5. 确认后进入“简历评分”，选择 PDF、DOCX 或 TXT 文件并开始评分。单份简历不超过 20 MB。
6. 在“评分进程”查看各文件的解析和评分状态。运行中的批次可暂停或继续；结束后可勾选失败文件并重新解析。解析失败的文件不会被当作低分候选人。

## 候选人与面试邮件

- 在岗位对应的“候选人”工作区查看评分结果、优势与评分理由、原文证据及复核提示。
- 可单独或批量设置“面试”“待定”“淘汰”。这些是 HR 流程标记，不会改变已计算的分数。
- 标记为“面试”的候选人会进入“邮件待发区”。核对候选人邮箱、编辑个人草稿及统一邮件模板后，可保存草稿或发送。发送前请确认收件地址、主题、时间、地点和正文；发送邮件属于对外操作。
- 邮箱为空或无效时，先手动补充有效邮箱。若发送状态显示“待核实”，先检查邮箱的已发送邮件，确认结果后再操作，避免重复发送。

## 邮箱收件与简历归档

- 启用邮箱自动收件后，系统按设置的检查周期收取新邮件。请让应聘者在邮件主题中写明唯一的岗位名称。
- 邮件正文检测到疑似云附件链接时，会单独标为“云附件待下载”并显示链接。需人工核对并下载简历，再通过岗位池手动上传；系统不会自动登录或下载第三方网盘内容。
- 岗位名称无法唯一匹配时，邮件会留在“邮件收件箱”供 HR 手动分配。云附件或邮件正文中的网盘链接不等同于普通附件，可能需要另行下载。
- 启用本地归档后，邮件收取和手动上传的简历都会按岗位及年月归档。同名文件不会覆盖已有文件；关闭归档不会删除已归档文件。

## 本机数据、更新与备份

- 岗位、候选人、评分进程、收件记录、邮件草稿及应用设置保存在当前 Windows 用户的本机应用数据目录中；不同 HR 账号或电脑之间不会自动共享。
- 覆盖安装新版通常会保留应用数据，但卸载选项、Windows 账户变更、手动删除应用数据目录或磁盘故障都可能导致数据不可用。安装包不是备份。
- 更新或更换电脑前，请先关闭应用，并备份本机应用数据目录及单独设置的简历归档目录。API Key 使用当前 Windows 用户账户的安全存储，换 Windows 账户或电脑后需要重新配置。
- 归档文件夹可能位于应用数据目录之外，必须单独备份。

## 常见问题

**模型连接失败**：确认 API Key、接口地址和模型名称与服务商提供的信息一致；网络或服务商故障也可能导致请求失败。

**评分按钮不可用**：先在岗位流程中确认评分标准；若待评分列表为空，先上传支持格式的简历。

**简历解析失败**：检查文件是否损坏、加密、超过 20 MB 或不属于支持格式，然后在评分进程中选择失败项重新解析。扫描件质量差时，OCR 结果也可能不完整，应人工查看原文件。

**邮件没有自动进入岗位**：检查自动收件开关、授权码和主题中的岗位名称；匹配有歧义时请在邮件收件箱中手动分配。

**评分结果有疑问**：查看评分理由、原文证据和缺失信息；模型评分仅用于辅助筛选，不应单独作为招聘决定依据。

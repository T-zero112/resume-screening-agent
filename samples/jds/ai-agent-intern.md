# AI Agent 开发实习生 JD

## 岗位职责

1. 参与 AI Agent 相关产品的开发与教学；
2. 使用 TypeScript 和 Python 进行项目开发，实现智能交互功能；
3. 协助团队进行算法调优、API 调用与集成；
4. 进行技术调研，跟进 AI 领域前沿技术；
5. 参与代码编写、测试和文档整理，确保项目顺利交付。

## 任职要求

1. 计算机、人工智能、软件工程等相关专业，本科及以上学历在校生；
2. 熟练掌握 TypeScript 和 Python，具备一定的开发经验；
3. 了解 AI 相关技术，如自然语言处理（NLP）、机器学习等，有相关项目经验者优先；
4. 具备良好的编程习惯，熟悉 Git 等版本管理工具；
5. 逻辑思维清晰，学习能力强，有团队协作精神。

## 加分方向

> 本项目不设置独立加分项。以下内容作为 JD 匹配评分维度的一部分。

- 有 AI Agent 或 Chatbot 相关开发经验；
- 熟悉 LLM 应用开发，如 OpenAI API、LangChain 等；
- 具备前端开发能力，如 React、Vue；
- 有 Dify 平台使用经验优先。
